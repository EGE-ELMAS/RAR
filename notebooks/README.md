# Notebooks

Notebooks in this repository are concise interfaces to the tested package.
They must not contain API keys, hard-coded Drive paths, copied implementation
blocks, protected outputs, or retained execution results containing clinical
text.

Entry points:

1. `01_prepare_authorized_data.ipynb`
2. `02_train_rar.ipynb`
3. `03_run_llm_experiments.ipynb`
4. `04_train_baselines.ipynb`
5. `05_evaluate_results.ipynb`
